## 1. 项目是什么

### 1.1 研究方向 **[已核实]**

仓库 `README.md` 定义研究方向：**Evidence-Guided Open-Ended Engineering Design**；方法名候选 **ECDR = Evidence-Conditioned Design-Space Revision**（`README.md:44-50` 自述三个名字混用、尚未统一）。

### 1.2 初稿给出的研究问题 **[已核实：来自用户提供的初稿]**

> **AI Agent 能否依据物理证据识别当前设计的能力缺口，并自主构造能够补足该缺口的工程结构？**

三个子挑战（初稿 §1 末）：

1. 区分**搜索不足 / 结构限制 / 模型误差**
2. 诊断必须能**约束后续生成**（缺失模态、时间尺度、能量路径 → 可实现的组件与连接）
3. 仿真有成本与误差，需**分配验证预算**并**保留值得继续探索的设计分支**

### 1.3 初稿的形式化骨架 **[已核实]**

- 设计对象 D=(S, theta)：S = 组件类型 + 连接拓扑 + 边界关系；theta ∈ Theta(S) = 该结构允许的连续参数
- 可实现行为集 B_z(S) = { F(S,theta;z) : theta ∈ Theta(S), g(S,theta) <= 0 }
- 最优可达误差 delta(S) = inf_theta L(F(S,theta;z), y*)；delta(S) > epsilon 即能力缺口
- 关键分解：**ell(S, that) = delta(S) + [ ell(S, that) - delta(S) ]** —— 第一项是结构差距，第二项是搜索尚未消除的差距
- 能力定义：**结构在规定条件下能够产生的一类可验证行为**（独立模态、不同热响应时间尺度、特定能量传递路径）
- 能力判据：**能否提出可被后续实验支持或否定的预测**

### 1.4 振动在初稿中的定位 **[已核实]**

初稿 §2.3–§2.4 的首个任务：输出 y*(t) = 0.7 cos 2t + 0.3 cos 5t。

- **命题 1**：单自由度被动线性无阻尼系统不能精确生成该轨迹。证明是初等的：代入后两个余弦线性无关，系数须同时为零，要求 w^2 = 4 且 w^2 = 25，矛盾。
- **§2.4 解析构造**：M = I，K = [[14.5, -10.5], [-10.5, 14.5]]，模态 (1,1) 与 (1,-1) 对应 w^2 = 4 与 25；取 q(0) = (1, 0.4)、q'(0) = 0 即得目标轨迹。
- 初稿明确声明：**"它不是 Agent 已经发现该设计的证据"**；且**"对已有机制的调用与对新机制的发现应当分别评价"**。
- 初稿明确：**"机械振动将作为首个研究领域"**。

## 3. 已核实的代码缺陷与实验缺陷

### 3.1 L1 鲁棒性目标函数符号错误 **[已核实，实跑复现]**

位置：`ecdr/l1/problem.py` 的 `MechanismProblemL1.evaluate()`：

```python
worst_obj = -np.inf
for d in self._dirs:
    ...
    worst_obj = max(worst_obj, -in_band)   # <-- 应为 min
```

目标被最大化，而存的是 -in_band，所以应取 **min**（等于最大的 in_band，即最坏情况）。当前代码取 max，**实际优化的是全部扰动方向中最乐观的那一个**。

实测（f_low = 210 Hz，M1，设计 [111.86361, 0.590427]）：

| 量 | 值 |
|---|---|
| `evaluate()` 返回的 in-band abs(T) | **0.095015** |
| 同 5 个方向上的**最大值** | **0.107885** |
| 同 5 个方向上的最小值 | 0.095015 |
| 逐方向值 | [0.095015, 0.10622, 0.097152, 0.097869, 0.107885] |
| `verify_l1(..., n_pert=24)` 独立验证 | **0.110556**（> 0.1，判不合格） |

**后果**：搜索不断把一个"看起来满足"的设计当成成功信号，然后被独立验证打回。这是 L1 消融中大量"未逃生"的直接原因。

**修正**：`worst_obj = min(worst_obj, -in_band)`。

**影响范围**：仅 L1。L0 的 `ecdr/bench/problem.py` 无多方向归约，**不受影响**。故 findings 001–008 与 L0 消融的结论安全。

### 3.2 搜索与验证使用不同的扰动方向集 **[已核实]**

- 搜索（`MechanismProblemL1`）：**5 个固定方向**，按问题种子固定，优化过程中不变
- 验证（`verify_l1`）：每次 n_pert 个方向（默认 24）**重新随机抽取**，种子默认 909
- 网格也不同：搜索 1500 点（0.05 → 1e5），验证 8000 点（0.02 → 2e5）

两者都是"最坏情况"估计，但**不是同一个最坏情况**。实测该差异量级较小：

- M1 @ 210 Hz：搜索 0.08973 / 验证种子 1,2,3,909 = 0.09713, 0.09691, 0.09716, 0.09866
- M2 @ 210 Hz：搜索 0.09869 / 验证 0.10558, 0.10703, 0.10667, 0.10946（**搜索通过、验证失败**）

**标注**：这是设计上的不一致，**不是** 3.1 那种符号错误。其正确性取决于"搜索用固定方向是否合理"这一设计判断 **[待定]**。

## 4. 双方达成的共识

### 4.1 关于项目定位

**[共识 1]** 振动是**首个实验领域**，不是论文主题。论文主张的是"能力缺口诊断 + 结构构造"这一方法的通用性。

**[共识 2]** 仓库当前的研究对象（固定拓扑下的频域约束满足 + 机制切换）与初稿的研究对象（结构 S 的能力缺口 + 构造新结构）**不是同一件事**，对象、失败定义、答案形式三者都不同。

**[共识 3]** 真实生产场景（EUV 发生器、高精度镜头模组加工等）的解空间**复杂到难以完全建模**；因此方法的适用性必须在大解空间下成立，而不是在玩具问题上成立。

### 4.2 关于"可证明"的地位

**[共识 4]** **"可证明"与"可校准 + 可撤销"不冲突。**

- 可证明 = **陈述**的静态属性；可撤销 = **知识库**的动态属性
- 两者互补：可证明的陈述**必然携带适用域**，适用域正是撤销的根据
- **真正危险的是"可证明但没写适用域"** —— 那才退化成硬门禁

**[共识 5]** findings/008 的"假阳性区"不是可证明性的反例，**正是上述机制的实证**：L0 证书在 172–240 Hz 宣布可行而 L1 下无一幸存 = **原证书的适用域被更高保真度越过**。

**[共识 6]** "可证明"在排查中的角色是**置信度算子**，不是过滤器：

- 无证明 → 置信度靠采样 / 趋势 / 代理模型累积，代价随维度增长，结论永远是"尚未找到"
- 有证明 → **一次论证直接坍缩掉该区域的全部置信度**，代价与维度无关，且可独立复核
- 这正是期望看到的"缩 / 放"

**[共识 7]** 证明的作用对应初稿 §2.2 的分解：**它直接给出 delta(S) 的下界并证明其超过容差，于是第二项（搜索尚未消除的差距）与决策无关。** 它排查的不是某个参数点，是整个参数区域。

### 4.3 关于 agent 与 harness

**[共识 8]** Agent 的本质是 **LLM + harness**。**LLM 是"智能"的 base。**

**[共识 9]** harness 的核心目的是**帮助 LLM 正确地思考和工作** —— 不是极端地提高模型上界，也不是极端地"all for 训练"。

**[共识 10]** 良好的 agent 设计**不应强行追求用精妙的 harness 把 agent 的能力边界做质变式提升**。

**[共识 11]** **不训练任何模型（包括验证器）。** 训练属于 **agent 的自进化**（深度学习 / 强化学习等），不属于某个验证器的训练。

**[共识 12]** 经过验证的 agent 科研方式是：**给出路径候选，然后排查。**

### 4.4 关于研究方法与文献

**[共识 13]** 我方引用的几篇文献中，给出测试的**解空间往往相对小 → 启发式存在优势**，因此不能直接用来支撑本方法。

**[共识 14]** 老旧文献有**时代局限**，不能轻易采信。

**[共识 15]** 因此论证路线应改为**从结构上论证**（启发式必须采样、代价随维度增长、结论可错；证明不需采样、可独立复核），而非引用权威结论。

**[共识 16]** 最应验证的是**交叉点**：固定证据强度下，"排除一个区域"的代价随设计空间规模如何变化。预期启发式代价快速增长、证明代价不变，两条曲线必然交叉。

### 4.5 关于当前状态

**[共识 17]** 当前进度的**真正瓶颈不是证书不够多，而是问题不够大**。在 2–5 维固定拓扑的箱子里，永远落在交叉点左侧，测不出证明的价值。

## 10. 一句话总纲

**本项目研究的是"AI Agent 能否依据物理证据识别结构的能力缺口，并自主构造补足该缺口的结构"；振动是首个领域而非主题；"可证明"在其中是排查候选时的置信度算子（携带适用域、因而可撤销），不是判定器；harness 的职责是让 LLM 正确思考与工作，不追求抬升能力上界，也不为训练服务；而当前最紧的瓶颈，是设计空间还太小，小到无法测出证明相对于启发式的价值。**
